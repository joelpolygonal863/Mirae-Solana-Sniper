## ⚙️ Configuration Setup

You must configure the application before you trade. Open the Settings menu to define your preferences.

### Wallet Connection
Navigate to the "Wallets" tab. You need to import a private key or a Seed Phrase. The tool uses this key to sign transactions on the blockchain. Create a new wallet specifically for sniping to keep your main funds separate and safe. Label the wallet clearly so you recognize it later.

### Trading Parameters
The "Trading" tab contains your automated rules. Define your order size in SOL. Set your slippage tolerance. Slippage determines how much price change you accept during a trade. A value between 0.5% and 2% works for most users. 

### Network Settings
The Jito Support feature helps you bypass network congestion. Enable this setting in the "Network" tab to send your trades directly to validators. This process helps your transaction get included in a block faster than standard methods.

## 🛠️ Troubleshooting Common Issues

If the software fails to launch, check your antivirus settings. Some security software misidentifies trading tools as threats. Add an exception for the Mirae-Solana-Sniper folder in your antivirus settings.

If the scanner показывает no new tokens, check your internet connection. A slow connection prevents the application from syncing with the blockchain. Restart the application to refresh the network handshake.

If you experience "Transaction Expired" errors, increase your gas fee or slippage settings. This indicates the network is busy, and your trade failed to confirm within the expected time window.
